Delete a medication record.

Deleting is permanent. To try it safely, create a throwaway record with POST /medications, copy the returned id, then delete that one.

path Parameters
id
required
string <uuid>
Example: 4984de2e-d9dd-45d9-99ac-4f292b3365c4

The unique identifier of the medication to delete.

Responses

Local development server

http://localhost:5000/api/medications/{id}

  • 500

{
  • "error": "Medication not found"
