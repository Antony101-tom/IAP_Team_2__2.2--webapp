## Meditrac Summary

Meditrac helps patients find medication at nearby pharmacies and lets pharmacies manage what they have in stock.

- Patients can search for a medication, see which registered pharmacies carry it, and view them on a map sorted by distance.
- Pharmacies can register, count, pin their location on a map, and manage their medication inventory from a dashboard.

## App Audit

### Everything the App Stores

**Users**
1. User info (name, email, address, password)
2. User location
3. User's tracked medicine
4. User's saved chemists

**Pharmacy**
1. Pharmacy info (name, email, password)
2. Medicine details (name, quantity, price)
3. Pharmacy location

### Actions Taken

**Users**
1. Create account
2. Login and logout
3. Search for medicine
4. View available medicine from registered pharmacies
5. Track medicine
6. Stop tracking medicine

**Pharmacies**
1. Create account
2. Login and logout
3. Add new medication and details
4. Save to inventory
5. Cancel addition of new medication
6. Pin pharmacy location
7. Save pharmacy location
